# Java Lab — Exercise 3

**Subject:** Object-Oriented Programming Through Java Lab  
**Exercise 3 topics:**
- (a) Class mechanism: define a class, create methods, and invoke methods from `main()`
- (b) Method overloading
- (c) Constructor
- (d) Constructor overloading

## Requirements
- Java JDK installed
- Command Prompt or terminal
- A text editor such as Notepad

## How to compile and run

Open Command Prompt and navigate to the folder containing these `.java` files.

### 3(a) Class and methods
```cmd
javac ClassDemo.java
java ClassDemo
```

### 3(b) Method overloading
```cmd
javac MethodOverloading.java
java MethodOverloading
```

### 3(c) Constructor
```cmd
javac ConstructorDemo.java
java ConstructorDemo
```

### 3(d) Constructor overloading
```cmd
javac ConstructorOverloading.java
java ConstructorOverloading
```

## Important notes
- Save each source file with exactly the same name as its `public class`, including `.java`.
- Java is case-sensitive.
- Compile with `javac FileName.java`, then run with `java ClassName`.
- Sample outputs are included in comments at the end of each source file.
