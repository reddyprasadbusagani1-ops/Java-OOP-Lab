# Java Lab — Exercise 5

## Programs
1. `SuperDemo.java` — Demonstrates the `super` keyword to access a parent class variable and method.
2. `InterfaceDemo.java` — Implements two interfaces in one class. This demonstrates multiple inheritance of type through interfaces in Java.
3. `RuntimePolymorphism.java` — Demonstrates runtime polymorphism using method overriding and a parent-class reference.

## Compile and run

Run the following commands in Command Prompt from this folder.

### 5(a) super keyword
```cmd
javac SuperDemo.java
java SuperDemo
```

### 5(b) Interface
```cmd
javac InterfaceDemo.java
java InterfaceDemo
```

### 5(c) Runtime polymorphism
```cmd
javac RuntimePolymorphism.java
java RuntimePolymorphism
```

Each Java source file contains the aim and code only. Sample output is not included.
