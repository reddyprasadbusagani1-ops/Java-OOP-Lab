# Java Lab — Exercise 2

**Course:** (23A05303P) Object-Oriented Programming Through Java Lab

## Programs

- `BinarySearch.java` — searches for an element in a sorted array.
- `BubbleSort.java` — sorts an array in ascending order using bubble sort.
- `StringBufferDemo.java` — demonstrates `delete()` and `deleteCharAt()`.

## Requirements

- Java Development Kit (JDK)
- Notepad and Windows Command Prompt (CMD), or another terminal

## Compile and run

Open CMD in this folder.

### 2(a) Binary search
```cmd
javac BinarySearch.java
java BinarySearch
```

### 2(b) Bubble sort
```cmd
javac BubbleSort.java
java BubbleSort
```

### 2(c) StringBuffer
```cmd
javac StringBufferDemo.java
java StringBufferDemo
```

When saving from Notepad, choose **Save as type: All Files** and ensure the filename ends in `.java`, not `.java.txt`.
