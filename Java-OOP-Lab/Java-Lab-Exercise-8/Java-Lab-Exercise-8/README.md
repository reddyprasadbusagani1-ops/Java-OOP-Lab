# Java Lab — Exercise 8

**Aim:** To create, import, and use a user-defined Java package.

## Files
- `mypack/Message.java` — Defines the `mypack` package and `Message` class.
- `PackageDemo.java` — Imports and uses the package class.

## Compile and run

Open Command Prompt in the `Java-Lab-Exercise-8` folder and run:

```cmd
javac -d . mypack\Message.java
javac PackageDemo.java
java PackageDemo
```

The `-d .` option places the compiled class in the correct package folder.

Java files contain the aim and code only; sample output is not included.
