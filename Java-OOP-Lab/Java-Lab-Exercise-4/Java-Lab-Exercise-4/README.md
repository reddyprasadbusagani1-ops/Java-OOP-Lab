# Java Lab — Exercise 4

## Programs
1. `SingleInheritance.java` — Demonstrates single inheritance.
2. `MultilevelInheritance.java` — Demonstrates multilevel inheritance.
3. `AbstractClassDemo.java` — Demonstrates an abstract class.

```cmd
java SingleInheritance
```

```cmd
javac MultilevelInheritance.java
```

```cmd
javac AbstractClassDemo.java
```
