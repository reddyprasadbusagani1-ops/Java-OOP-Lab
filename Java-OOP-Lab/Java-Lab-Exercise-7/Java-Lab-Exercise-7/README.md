# Java Lab — Exercise 7

The Java source files contain the **aim and code only**. Sample output is not included.

## Programs
1. `ThreadDemo.java` — Create a thread by extending the `Thread` class.
2. `AliveJoinDemo.java` — Demonstrate `isAlive()` and `join()`.
3. `DaemonDemo.java` — Demonstrate a daemon thread.
4. `ProducerConsumer.java` — Producer-Consumer problem using `wait()` and `notifyAll()`.

## Compile and run

Open Command Prompt in this folder and run each program separately.

```cmd
javac ThreadDemo.java
java ThreadDemo
```

```cmd
javac AliveJoinDemo.java
java AliveJoinDemo
```

```cmd
javac DaemonDemo.java
java DaemonDemo
```

```cmd
javac ProducerConsumer.java
java ProducerConsumer
```
